# Minimum thickness and stereotomy

Semicircular arch of radius R = 1000 mm and 100 blocks under self-weight, with radial joints or with vertical joints. A negligible reference load of 0.001 N acts on the crown block, so that the sign of the multiplier shows whether the self-weight alone admits a thrust line inside the arch: a positive multiplier means the thickness is sufficient, a negative one that it is not.

| File | Joints | t/R | ExcelLAR λu |
|---|---|---|---|
| `Semicircle100_radial_tR0.1075.csv` | radial | 0.1075 | positive |
| `Semicircle100_radial_tR0.1074.csv` | radial | 0.1074 | negative |
| `Semicircle100_vertical_tR0.1094.csv` | vertical | 0.1094 | positive |
| `Semicircle100_vertical_tR0.1092.csv` | vertical | 0.1092 | negative |

The minimum thickness found by ExcelLAR is therefore t/R = 0.1075 with radial joints and 0.1093 with vertical joints, against 0.1075 and 0.1095 in Makris and Alexakis (2013). The files were generated by `validation/minthick.py`, which also solves the same problem independently in Python with up to 400 blocks.
